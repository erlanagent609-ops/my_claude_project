# Dynamic Problem Solver Skill (Upgraded)

This skill enables the agent to autonomously detect missing capabilities, create new skills or update existing wrappers/scripts, and provide direct, complete answers without requiring the user to prompt multiple times, enhanced with web-search capabilities and automated error self-healing.

## Core Protocols
1. **Proactive Adaptation**: When a user request cannot be met with existing tools or scripts, immediately design and implement the required python script, wrapper, or skill documentation.
2. **Autonomous Execution**: Test and integrate the new capability into the workspace.
3. **Direct Resolution**: Answer the user's request completely and naturally in the requested language using the newly established capability.
