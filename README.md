# My Claude Project

## Project Overview
This project contains source code, scripts, documentation, and agent skills.

## Adding New Skills
To add a new skill for the agent:
1. Create a new markdown file inside the `skills/` directory (e.g., `skills/my_new_skill.md`).
2. Define the core principles, guidelines, and step-by-step instructions for the agent within the markdown file.
3. Commit the changes to version control so the agent can reference the new guidelines in future tasks.
