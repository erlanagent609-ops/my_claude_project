# Weather Fetcher Guide

This guide explains how to use the `scripts/weather_fetcher.py` script to retrieve real-time weather data from the public Open-Meteo API.

## Prerequisites

The script uses Python's built-in standard libraries (`urllib.request` and `json`), so no external packages (like `requests`) or API keys are required.
